# 战斗属性组件扩展方案解析
基于现有`Stats`类的设计逻辑，针对“暴击系统”“状态效果”“属性成长”三个扩展需求，可通过**类内属性新增+功能方法补充**的方式实现，确保与原有战斗机制（如伤害计算、状态管理）兼容，以下是具体方案：


## 一、暴击系统：扩展暴击率与暴击伤害属性
核心逻辑是在原有“攻击力”基础上，新增“暴击概率”和“暴击倍率”属性，在计算伤害时通过随机值判断是否触发暴击，再按倍率放大伤害。

### 1. 新增属性（Stats.h 类内 protected 区）
```cpp
float crit_chance_ = 0.1f;    // 暴击率（默认10%，范围0~1）
float crit_multiplier_ = 1.5f;// 暴击伤害倍率（默认1.5倍，即150%伤害）
```

### 2. 补充功能（Stats.h 类内 public 区）
- **Getter/Setter**：用于外部（如装备系统）调整暴击属性
  ```cpp
  float getCritChance() const { return crit_chance_; }
  void setCritChance(float chance) { crit_chance_ = glm::clamp(chance, 0.0f, 1.0f); } // 限制0~1，防止异常值
  float getCritMultiplier() const { return crit_multiplier_; }
  void setCritMultiplier(float multiplier) { crit_multiplier_ = glm::max(multiplier, 1.0f); } // 倍率不低于1（避免负暴击）
  ```
- **暴击判断与伤害计算**：新增方法替代原直接用`damage_`的逻辑，供外部调用（如Enemy的attack()）
  ```cpp
  float calculateDamage() {
      float final_damage = damage_;
      // 生成0~1的随机值，若小于暴击率则触发暴击
      if (rand() / (float)RAND_MAX < crit_chance_) {
          final_damage *= crit_multiplier_;
          SDL_Log("暴击！伤害：%f", final_damage); // 反馈暴击效果
      }
      return final_damage;
  }
  ```

### 3. 外部调用修改（示例：Enemy的attack()）
原逻辑直接用`stats_->getDamage()`，改为调用新的计算方法：
```cpp
target_->takeDamage(stats_->calculateDamage()); // 自动判断是否暴击
```


## 二、状态效果：实现中毒效果（每秒造成伤害）
核心逻辑是新增“状态效果管理容器”，存储当前生效的状态（如中毒），在`update()`中逐帧处理状态的持续时间、触发间隔与效果（如每秒扣血）。

### 1. 定义状态结构体（Stats.h 类外/内部）
先定义通用状态结构，支持不同效果类型（此处以中毒为例，可扩展燃烧、减速等）：
```cpp
// 状态类型枚举
enum class StatusType {
    POISON,   // 中毒：每秒扣血
    BURN,     // 燃烧（预留）
    SLOW      // 减速（预留）
};

// 单个状态的数据结构
struct StatusEffect {
    StatusType type;       // 状态类型
    float duration;        // 总持续时间（秒）
    float remaining_time;  // 剩余持续时间（秒）
    float tick_interval;   // 效果触发间隔（秒，如1秒1次）
    float tick_timer;      // 触发间隔计时器（秒）
    float effect_value;    // 效果数值（如中毒每秒扣5血）
};
```

### 2. 新增属性与方法（Stats.h）
- **状态容器**（protected区）：存储当前生效的所有状态
  ```cpp
  std::vector<StatusEffect> active_statuses_;
  ```
- **public方法**：添加状态、移除状态、处理状态逻辑
  ```cpp
  // 添加状态（外部调用，如敌人攻击附加中毒）
  void addStatus(StatusType type, float duration, float tick_interval, float effect_value) {
      // 先检查是否已有同类型状态（可选：覆盖/叠加，此处以覆盖为例）
      for (auto& status : active_statuses_) {
          if (status.type == type) {
              status.remaining_time = duration; // 覆盖持续时间
              status.tick_timer = 0;            // 重置间隔计时器
              return;
          }
      }
      // 无同类型状态则新增
      active_statuses_.push_back({type, duration, duration, tick_interval, 0, effect_value});
  }

  // 处理状态效果（在update()中调用）
  void handleStatusEffects(float dt) {
      for (auto it = active_statuses_.begin(); it != active_statuses_.end();) {
          auto& status = *it;
          // 1. 更新持续时间：持续时间耗尽则移除状态
          status.remaining_time -= dt;
          if (status.remaining_time <= 0) {
              it = active_statuses_.erase(it);
              continue;
          }
          // 2. 更新间隔计时器：到间隔则触发效果
          status.tick_timer += dt;
          if (status.tick_timer >= status.tick_interval) {
              switch (status.type) {
                  case StatusType::POISON:
                      // 中毒效果：扣血（调用已有takeDamage，自动触发无敌判断）
                      takeDamage(status.effect_value);
                      SDL_Log("中毒！每秒扣血：%f，剩余时间：%f", status.effect_value, status.remaining_time);
                      break;
                  // 可扩展其他状态（如燃烧、减速）
                  default:
                      break;
              }
              status.tick_timer = 0; // 重置间隔计时器
          }
          ++it;
      }
  }
  ```

### 3. 集成到update()（Stats.cpp）
在原有`update()`中添加状态处理逻辑，确保逐帧运行：
```cpp
void Stats::update(float dt) {
    Object::update(dt);
    regenMana(dt);
    handleStatusEffects(dt); // 新增：处理状态效果
    // 原有无敌时间逻辑...
}
```

### 4. 外部调用示例（如Enemy附加中毒）
在敌人攻击时，给玩家添加中毒状态：
```cpp
// enemy.cpp 的attack()中，碰撞检测通过后
if (stats_ && target_->getStats()) {
    target_->takeDamage(stats_->calculateDamage());
    // 附加中毒：持续5秒，每秒扣3血
    target_->getStats()->addStatus(StatusType::POISON, 5.0f, 1.0f, 3.0f);
}
```


## 三、属性成长：实现等级与属性升级系统
核心逻辑是新增“等级”“升级所需经验”属性，通过“添加经验→判断是否升级→按规则提升属性”的流程，实现角色成长。

### 1. 新增属性（Stats.h protected 区）
```cpp
int level_ = 1;               // 当前等级（默认1级）
int current_exp_ = 0;         // 当前经验值
int exp_to_next_level_ = 100; // 升级所需经验（默认1级升2级需100经验）
// 升级属性成长系数（每升1级，属性提升的比例/固定值）
float health_growth_ = 0.2f;  // 生命值+20%
float mana_growth_ = 0.15f;   // 魔法值+15%
float damage_growth_ = 0.1f;  // 攻击力+10%
```

### 2. 补充功能（Stats.h public 区）
- **Getter**：外部获取等级、经验信息
  ```cpp
  int getLevel() const { return level_; }
  int getCurrentExp() const { return current_exp_; }
  int getExpToNextLevel() const { return exp_to_next_level_; }
  ```
- **添加经验与升级逻辑**：
  ```cpp
  // 添加经验（外部调用，如击杀敌人后）
  void addExp(int exp) {
      if (exp <= 0) return;
      current_exp_ += exp;
      SDL_Log("获得经验：%d，当前经验：%d/%d", exp, current_exp_, exp_to_next_level_);
      // 循环判断是否连续升级（如经验远超升级需求）
      while (current_exp_ >= exp_to_next_level_) {
          levelUp(); // 执行升级
      }
  }

  // 升级核心逻辑（私有/保护，仅内部调用）
  void levelUp() {
      // 1. 扣除升级经验，计算下一级所需经验（按固定倍率增长，如1.5倍）
      current_exp_ -= exp_to_next_level_;
      exp_to_next_level_ = static_cast<int>(exp_to_next_level_ * 1.5f);
      // 2. 提升等级
      level_++;
      SDL_Log("升级！当前等级：%d", level_);
      // 3. 提升属性（按成长系数计算，更新最大生命值/魔法值，并补满当前值）
      float old_max_health = max_health_;
      max_health_ *= (1 + health_growth_); // 生命值+20%
      health_ = max_health_; // 升级后满血
      
      float old_max_mana = max_mana_;
      max_mana_ *= (1 + mana_growth_); // 魔法值+15%
      mana_ = max_mana_; // 升级后满魔
      
      damage_ *= (1 + damage_growth_); // 攻击力+10%
      
      // 4. 输出属性变化日志
      SDL_Log("属性提升：生命值 %f→%f，魔法值 %f→%f，攻击力 %f→%f",
              old_max_health, max_health_,
              old_max_mana, max_mana_,
              old_max_mana / (1 + mana_growth_) * damage_growth_, damage_);
  }
  ```

### 3. 外部调用示例（如击杀敌人后给玩家加经验）
在敌人死亡逻辑中，给玩家添加经验：
```cpp
// 假设enemy_die()为敌人死亡处理函数
void Enemy::enemy_die(Player* player) {
    if (player && player->getStats()) {
        // 击杀敌人获得50经验
        player->getStats()->addExp(50);
    }
    // 敌人死亡其他逻辑（如消失、掉落）...
}
```


## 总结
三个扩展功能均遵循**“最小侵入”原则**：
1. 基于原有`Stats`类新增属性，不修改核心方法（如`takeDamage` `update`）的基础逻辑；
2. 功能封装为独立方法（如`calculateDamage` `handleStatusEffects` `levelUp`），便于后续扩展（如新增暴击音效、多状态叠加规则、等级上限）；
3. 外部调用通过`Getter/Setter`或专用方法（如`addStatus` `addExp`）实现，与Actor类、战斗交互逻辑（如攻击、死亡）无缝兼容。
