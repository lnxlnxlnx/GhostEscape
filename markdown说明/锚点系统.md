# 锚点系统扩展功能解析
基于现有锚点系统（9个固定参考点），以下对4个扩展功能的核心逻辑、实现思路及应用价值进行简要解析：


## 1. 自定义百分比锚点（如25%宽度，75%高度）
### 核心逻辑
突破“固定9个锚点”的限制，允许开发者通过**宽度百分比（0-100%）** 和**高度百分比（0-100%）** 自定义参考点，本质是将“离散锚点”升级为“连续锚点坐标”。

### 实现关键
- **参数设计**：新增`setCustomAnchor(float widthPercent, float heightPercent)`方法，接收0-1或0-100的百分比值（需统一单位，如约定输入为0-1浮点数）。
- **偏移计算**：将原固定锚点的“硬编码偏移”改为“动态百分比计算”，公式为：  
  `offsetX = - (size.x * widthPercent)`（X轴偏移，基于宽度百分比）  
  `offsetY = - (size.y * heightPercent)`（Y轴偏移，基于高度百分比）  
  例：25%宽度（0.25）、75%高度（0.75）的锚点，偏移为`(-size.x*0.25, -size.y*0.75)`，对应组件“25%宽度处、75%高度处”与父对象位置重合。
- **兼容性**：保留原枚举锚点（如`CENTER`可映射为`widthPercent=0.5, heightPercent=0.5`），确保旧代码可用。

### 应用价值
满足非标准定位需求，如“UI按钮左边缘20%处对齐父对象”“角色武器挂点（非中心/边角）定位”。


## 2. 锚点动画：组件在不同锚点间平滑过渡
### 核心逻辑
通过**插值计算**让组件从“当前锚点”到“目标锚点”的偏移量、位置逐步变化，而非瞬间切换，实现“平滑过渡”效果。

### 实现关键
- **状态记录**：在`ObjectAffiliate`中新增“目标锚点（targetAnchor）”“过渡时长（duration）”“已过渡时间（elapsedTime）”变量，标记动画状态。
- **插值计算**：每帧更新时，根据`elapsedTime/duration`计算“插值系数（0-1）”，用**线性插值（Lerp）** 过渡偏移量：  
  1. 计算当前锚点的偏移量（currentOffset）和目标锚点的偏移量（targetOffset）；  
  2. 帧偏移量 = Lerp(currentOffset, targetOffset, 插值系数)；  
  3. 当`elapsedTime >= duration`时，结束动画，将锚点设为targetAnchor。
- **扩展能力**：支持添加“缓动函数（如先慢后快）”，让过渡更自然（如使用`pow(插值系数, 2)`实现缓入效果）。

### 应用价值
用于UI交互（如弹窗从“屏幕中心”过渡到“屏幕顶部”）、角色动画（如角色从“脚部对齐地面”过渡到“腰部对齐平台”）。


## 3. 相对锚点：组件相对于另一个组件的锚点定位
### 核心逻辑
打破“仅相对于父对象定位”的限制，允许组件A的锚点“依附于组件B的某个锚点”，实现“跨组件关联定位”。

### 实现关键
- **依赖记录**：在`ObjectAffiliate`中新增“参考组件（refComponent）”“参考组件的锚点（refAnchor）”变量，标记依赖关系。
- **位置计算**：每帧更新组件位置时，不再仅依赖父对象位置，而是：  
  组件最终位置 = 参考组件的位置 + 参考组件在`refAnchor`下的偏移量 + 当前组件自身的偏移量  
  例：组件A（锚点TOP_CENTER）依附于组件B（锚点BOTTOM_CENTER），则A的位置 = B的位置 + B的BOTTOM_CENTER偏移 + A的TOP_CENTER偏移，实现“A在B正下方对齐”。
- **动态更新**：若参考组件（B）的位置、大小变化，当前组件（A）会自动同步更新位置，保持相对关系。

### 应用价值
用于关联UI（如“按钮下方的提示框”始终对齐按钮底部）、角色挂载物（如“角色手中的武器”始终对齐角色的“手部锚点”）。


## 4. 网格布局：用锚点系统实现自动排列
### 核心逻辑
基于锚点的“统一定位逻辑”，按“行/列”规则计算每个组件的位置，自动将组件排列成网格（如3行2列），无需手动设置每个组件的位置。

### 实现关键
- **网格参数**：创建“网格管理器（GridLayout）”类，接收“列数（cols）”“行间距（rowGap）”“列间距（colGap）”“网格锚点（如TOP_LEFT）”参数。
- **位置分配**：  
  1. 计算单个“网格单元格”的大小（如父对象宽度/cols - 列间距，确保总宽度适配）；  
  2. 对每个组件，按“索引（index = 行号*cols + 列号）”计算其在网格中的位置：  
     组件X位置 = 网格起始X + 列号*(单元格宽度 + 列间距)  
     组件Y位置 = 网格起始Y + 行号*(单元格高度 + 行间距)  
  3. 为每个组件设置“网格锚点”（如TOP_LEFT），确保组件在单元格内对齐。
- **自适应调整**：当父对象大小变化时，网格管理器自动重新计算单元格大小和组件位置，保持网格布局。

### 应用价值
用于批量UI排列（如背包格子、技能图标）、场景元素布局（如地图中均匀分布的敌人 spawn 点）。
